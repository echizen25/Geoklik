GeoKlik offline/location reference data

Province + City/Municipality fallback
-------------------------------------
Full administrative reference data is sourced from Open Admin Data Philippines:
https://github.com/open-admin-data/philippines-administrative-divisions

License: Creative Commons Attribution 4.0 International (CC BY 4.0).
This dataset is packaged at build time and used only as an offline reverse-location fallback.
Coordinates are representative administrative points and are not survey-grade boundary determinations.

Infrastructure barangay validation
----------------------------------
Barangay boundary GeoJSON is sourced from philippines-json-maps:
https://github.com/faeldon/philippines-json-maps

License: MIT.
GeoKlik pins the boundary source to a fixed repository revision and downloads only the selected
Infrastructure project's municipality boundary file when needed. The file is cached in app-private
storage so subsequent checks can work offline. The source repository states that its 2023
administrative boundary data uses PSGC data updated as of 31 December 2023.

GeoKlik treats missing or unresolvable Infrastructure barangay boundary data as a blocked capture
rather than silently bypassing the project-location check.
